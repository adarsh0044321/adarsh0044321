## 📂 Featured Projects

### 🛰️ [Beacon Pulse](https://github.com/adarsh0044321/beacon-pulse)
> **Low-latency LAN remote screen-sharing, monitoring, and input-collaboration system for Windows.**
>
> - **Core Technologies:** `Rust` | `WinAPI` | `Tokio` (Asynchronous Runtime)
> - **Current Status:** Active Development
> - **Key Innovation:** Optimized desktop frame-capture and input-replication latency to **under 50ms** by bypassing standard high-overhead Windows rendering pipelines and implementing lock-free ring buffers in Rust.

<br>

### 🧠 [FocusFlow](https://github.com/adarsh0044321/focusflow)
> **AI-powered educational assistant featuring optical character recognition (OCR) and local AI execution.**
>
> - **Core Technologies:** `Python` | `PyQt5` | `OpenAI API` | `Tesseract OCR`
> - **Current Status:** Operational & Open Source
> - **Key Innovation:** Developed a lightweight desktop overlay that captures coordinates, extracts handwriting/text in real-time, and queries local or remote LLMs to provide instantaneous question evaluation and learning feedback.

<br>

### 👁️ [Copy Checker](https://github.com/adarsh0044321/copychecker)
> **Automated answer-sheet evaluation system leveraging computer vision and deep learning models.**
>
> - **Core Technologies:** `Python` | `OpenCV` | `TensorFlow` | `NumPy`
> - **Current Status:** Prototyping & Research
> - **Key Innovation:** Built a custom image processing pipeline that corrects scan perspectives, filters alignment markers, and utilizes deep convolutional networks to grade bubble sheets and handwriting with **over 95% classification accuracy**.
